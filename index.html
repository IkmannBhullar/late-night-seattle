ClinicRecall

Patient-recall SaaS for medical practices. Import patients by CSV, catch who's overdue, send reminder emails, track visits, and let the next due date recalculate itself.

  • Multi-tenant isolation at the repository layer, backed by Postgres row-level security
  • Idempotent reminders, so nobody gets the same email twice
  • 576 backend tests, plus a Playwright end-to-end walkthrough
  • Synthetic data only; intentionally labeled not HIPAA compliant
